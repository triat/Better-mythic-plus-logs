# In-app Help page (`/help`, `/api/docs`, contextual "?" links) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user of the web UI understand and verify every number: a `/help` page (canvas layout **A**: sticky sidebar table of contents + long page) that explains what bmpl looks at, how the verdict and every sub-signal are computed and why some are `n/a`, with the **effective** evaluation config (weights, curves, thresholds) printed live; small "?" links (canvas variant **a**) on the verdict, each axis, each evidence line, the run list and the deep-dive panel that jump to the matching section.

**Architecture:** `src/evaluation/docs.ts` is a typed registry of English prose keyed by the sub-signal ids of `default-config.json` (a test enforces the one-to-one match). `GET /api/docs` (public, both modes) returns the registry plus the effective config. The front renders it: pure models in `web/src/lib/help.ts`, thin components in `web/src/components/help/`, a `HelpLink` component for the five contextual spots, `/help` served as an SPA entry point like `/settings`.

**Tech Stack:** Bun + TypeScript strict, `bun test`; Vite 8 + React 19; inline SVG for the curve charts (no library).

**Spec:** `docs/superpowers/specs/2026-09-19-documentation-and-help-design.md` §3–§6. Design: canvas https://claude.ai/artifact/3yUjZKgaQyHKebzyqcio5s page "Hosted", artboards `HelpA.dc.html` (chosen), `HelpDetails.dc.html` (variant **a** of the "?" affordance, verdict hero, header link, user menu, key-level scaling section); sources in `docs/design/canvas/` (uncommitted until Task 5). Depends on plan `2026-09-19-docs-restructure.md` only for the README link in Task 5.

## Global Constraints

- **Every sentence in the registry is true of the code** — the reviewer of Task 1 checks each sub-signal's `how`/`naWhen` against `src/evaluation/inputs.ts`, `src/evaluation/axes/*.ts`, `src/signals/wcl-run.ts`, `src/signals/peers.ts`, `src/deepdive/analyze.ts` + `aggregate.ts`. **No number that lives in the config appears in the prose** (weights, curve points, `invite`/`maybe`/`minRuns`, `high`/`medium`, `consistencyMinRuns`, `deepdiveMinRuns`, level factors, expected ilvl): the front prints them from `config`. Allowed literals: structural facts (six axes, three roles, "the other four players", the 15-second / 3-death wipe rule, the 14-day stale badge, the 6-hour reuse of a lookup, ≈ 10 / ≈ 3 WCL points).
- **Registry ↔ config completeness**: for every axis, `Object.keys(EVALUATION_DOCS.axes[k].subSignals)` equals `Object.keys(DEFAULT_CONFIG.axes[k].subSignals)` (both directions); the `experience.prevSeasonBonus` evidence source is documented under `axes.experience.extras`.
- **`GET /api/docs`**: `auth: "public"`, both modes, `Cache-Control: no-store`, 0 WCL points, no per-user or env-derived data; `config` is `getEvalConfig()` (defaults ⊕ `evaluation.json`); `season` = the **last** key of `config.expectedIlvl` (the newest known season — `src/evaluation/axes/preparation.ts` uses the last key as the fallback; the spec said "first", this plan corrects it).
- **Front**: layout A of the canvas; colours/radii/fonts only from `tokens.css`; local `/` pixel-identical except the "Help" header link and the "?" glyphs; anonymous hosted visitors can read `/help`; `hostedOnly` FAQ entries render only when `status.hosted`; models pure and tested, components thin; types-only imports from `src/` via `web/src/types.ts`.
- **"?" affordance = variant a**: a 14 px circled `?` (`help-link` class: `display:inline-flex; width:14px; height:14px; border-radius:50%; border:1px solid var(--border); color:var(--faint); font-size:10px; margin-left:6px; vertical-align:1px`), `title="How is this computed?"`, `href="/help#…"`, `onClick={(e) => e.stopPropagation()}` so it never toggles the axis row it sits in.
- **Never spend WCL points**; `just check && bun test` green with `web/dist` absent at the end of every task; explicit `git add`; never `biwaasham.json`, `defensives.json`, `evaluation.json`, `.env`, `bmpl.db*`, `web/dist`; commit trailers as the session provides.

```ts
import type { AxisKey } from "./types.ts";

export interface SubSignalDoc {
  title: string; what: string; source: string; how: string; why: string; naWhen: string;
  /** What the curve's x axis is, e.g. "deaths per run, level-scaled". */
  unit: string;
  /** True when the value is multiplied by levelScale(run key level) before the curve. */
  scaledByLevel: boolean;
}
export interface ExtraDoc { title: string; what: string; how: string; why: string }
export interface AxisDoc { title: string; summary: string; why: string; subSignals: Record<string, SubSignalDoc>; extras?: Record<string, ExtraDoc> }
export interface TextBlock { title: string; text: string }
export interface SourceDoc extends TextBlock { freshness: string }
export interface FaqEntry { q: string; a: string; hostedOnly?: boolean }
export interface EvaluationDocs {
  axes: Record<AxisKey, AxisDoc>;
  verdict: { summary: string; global: string; thresholds: string; confidence: string; insufficient: string; role: string };
  levelScale: string;
  expectedIlvl: string;
  peers: string;
  runsUsed: string;
  notScored: TextBlock[];
  runSignals: TextBlock[];
  deepdive: { summary: string; usage: string; deaths: string; table: string; cost: string };
  sources: SourceDoc[];
  faq: FaqEntry[];
}
export const EVALUATION_DOCS: EvaluationDocs;
```

```ts
import { describe, expect, test } from "bun:test";
import { DEFAULT_CONFIG } from "../../src/evaluation/config.ts";
import { EVALUATION_DOCS } from "../../src/evaluation/docs.ts";
import { AXIS_KEYS } from "../../src/evaluation/types.ts";

const nonEmpty = (o: object, path: string) => {
  for (const [k, v] of Object.entries(o)) {
    if (typeof v === "string") expect(v.trim().length, `${path}.${k}`).toBeGreaterThan(0);
    else if (v && typeof v === "object") nonEmpty(v, `${path}.${k}`);
  }
};

describe("EVALUATION_DOCS", () => {
  test("documents exactly the sub-signals of the default config, per axis", () => {
    for (const k of AXIS_KEYS) {
      expect(Object.keys(EVALUATION_DOCS.axes[k].subSignals).sort()).toEqual(Object.keys(DEFAULT_CONFIG.axes[k].subSignals).sort());
    }
  });
  test("every string is non-empty", () => nonEmpty(EVALUATION_DOCS, "docs"));
  test("scaledByLevel marks exactly the two death counts", () => {
    const scaled = AXIS_KEYS.flatMap((k) => Object.entries(EVALUATION_DOCS.axes[k].subSignals).filter(([, d]) => d.scaledByLevel).map(([id]) => `${k}.${id}`));
    expect(scaled.sort()).toEqual(["survival.groupDeaths", "survival.individualDeaths"]);
  });
  test("the previous-season bonus (an evidence source outside the config) is documented", () => {
    expect(EVALUATION_DOCS.axes.experience.extras?.prevSeasonBonus?.title).toBe("Previous season bonus");
  });
  test("prose never hard-codes config numbers", () => {
    const text = JSON.stringify(EVALUATION_DOCS);
    for (const n of [String(DEFAULT_CONFIG.verdict.invite), String(DEFAULT_CONFIG.verdict.maybe), "300 pts", "3600"]) expect(text).not.toContain(n);
  });
  test("hostedOnly FAQ entries exist and are flagged", () => {
    expect(EVALUATION_DOCS.faq.some((f) => f.hostedOnly)).toBe(true);
    expect(EVALUATION_DOCS.faq.some((f) => !f.hostedOnly)).toBe(true);
  });
});
```
